Advanced: relays and provenance

Relays

Reader starts with six public relays and requires any two to accept each encrypted payload. You can add up to two custom relays.

    Custom addresses must use wss://. Android checks public DNS destinations during pairing and before every sync.

    The saved relay list differs from the connected device. Re-pair to authenticate and apply it on both sides.

    Site access

    Enable inline Reader buttons only on sites you choose. Toolbar capture works on the current tab when you click Reader.

    Signing

    Private device key (Recommended) is default. Browser signer lives under Advanced.
