# Reader copy and behavior contract

Updated 2026-09-10 for the user-approved focused implementation, then again after the shared-header, compact-search and prominent-Review pass, and again on 2026-09-11 for the final usability pass (Reader rename, four reading actions, once-only highlight help, warmer #FFF1E5 Paper surface), the quote-tap Review pass (full quote cards, Review from a tapped quote without losing the round), the Inter reading font, the refined Find-in-article sheet, the app-wide E-ink / NXTPAPER theme, the 2026-09-11 polish pass (single-identity continuous highlighting, legible monochrome controls, named highlight identities, corrected Review counts, filled Review entry with header fallback, mutually-exclusive Find states, per-element extraction boundaries), and the focused source-context repair (source → full quote → compact actions, fixed Review source row, user-sized adaptive quote type). The Chrome text-boundary fix changes capture output, not UI copy. Superseded rows are replaced rather than kept. UI copy and its assertions change together.

## Voice

Use clear, quiet language. Describe the stored outcome accurately and give a useful next action. Never claim an article is available offline before its text is stored. No streak pressure, automatic tutorial labels or unsolicited celebrations.

## Main surfaces

| Surface | Copy | Behavioral contract |
|---|---|---|
| Bottom navigation | Reader · Highlights · Settings | Hidden in the reader, quote detail and Review. Re-selecting preserves position. Visible name only; internal `shelf` ids and routes are unchanged. |
| Destination header | Reader · Highlights · Settings · Review · Review all | One shared row: 52dp minimum height, 20dp leading inset, common headline typography and vertical alignment. Highlights carries a quiet trailing Review action (at least 48dp tall; on its own short row below the title at enlarged text) so Review is always one tap away. While search or Important filter is active the header action reads Review all to keep the global scope explicit. Height grows with the system text scale instead of clipping. Reader's Search and Add stay at least 48 × 48dp. |
| Shelves | Inbox · Priority · Later · Archive | All visible, wrapping at enlarged text; counts outside the tabs. |
| Shelf rows | Title · source · remaining time · Done pill | The title stays dominant: the per-source marker is a short 22dp accent paired with the source name in the meta line, and in-progress progress is a thin muted stroke. Unread, in-progress, At end, Finished and Link only are distinguished by text, never by colour alone. |
| Resume | Continue reading | Actual reading activity, unfinished and non-archived; hidden while searching, filtering or selecting. |
| First save | Add your first article | Opens saving choices; sample reading is optional. |
| Save sheet | Paste a link or text · Import a file · Connect Chrome | Android sharing also works without pairing. |
| Capture | Link saved — fetching article | Link accepted, extraction unfinished. Ready feedback follows stored text. |
| Link fallback | Link only | Does not imply offline article text. Retry uses the existing capture request. |
| Article state | Unread · At end · Finished | Finished depends on explicit completion, never a scroll percentage alone. |
| Reading controls | Highlight · Contents · Listen · Speed | Four equal-width icon-above-label actions, 20–22dp icons, ~12sp labels, each ≥48dp and the row ~56dp. At enlarged text they wrap to a 2×2 grid; the row never scrolls sideways or shrinks. Listen becomes Pause while speaking; resuming reuses the existing speech session. Speed pauses speech and flushes pending reading/selection changes. The overflow menu keeps the same equivalents. |
| Highlight help | Keep a passage · Start highlighting | Shown once, on the first Highlight attempt of a new install (`highlightCoachSeen`); installs with existing preferences start seen and skip it. Marked seen when presented, including dismissal. Copy: Press and hold a word, then adjust the handles. Your selection is highlighted and saved automatically. Choose a color below; tap Done to leave highlighting. |
| Appearance | Text size · Spacing · Background · Font, margins & bold | Bottom sheet; advanced controls scroll; changes apply immediately and retain the passage. Bundled reading fonts are Newsreader (new-install default), Crimson Pro, Asul, Atkinson Hyperlegible, ABeeZee and Inter, each shipped offline with normal and bold faces (no download during use); changing font preserves the semantic position. App chrome itself stays Atkinson. |
| Theme | Follow app theme | Inherits the app theme, which can itself follow the system. |
| App theme | Follow system · Light · Dark · E-ink / NXTPAPER | Settings › App theme. E-ink forces a white/black monochrome presentation (white ground, black text, #333 secondary, inverted selected controls, underlined links, star/important and errors by shape or text) with reduced motion and static loading text. While it is active, Appearance states that the app-wide theme owns the background instead of showing Paper as the effective background. The saved reading background and font survive underneath and return when the theme is left. |
| E-ink loading | Opening… · Opening speed reader… · Preparing review… | Static progress text replaces the animated spinner in the E-ink theme. |
| Find in article | Find in article · Word or phrase · N of M · Previous match · Next match · Return to reading position | Opened from the reader's navigation menu; a compact sheet about 55% of usable height (expanding to 90% when the keyboard or enlarged text needs it) with a stable header and field and independently scrollable results, using the reader's colours. Field placeholder is Word or phrase with a Clear search action. Explicit mutually-exclusive states: blank guide ("Search the article text stored on this device."), busy ("Searching all parts…"), no match ("No matches for “<query>”."), results, or failure with Retry for the same query — failure never doubles as "no matches", and a new request clears stale errors. The active result shows "N of M" with Previous match / Next match; each result is a full-width row with a two- or three-line context snippet, the matched phrase emphasised, a strong selected-row marker (leading bar plus outline with selected semantics, never fill alone) and "Part N" only for multi-part articles. Case-insensitive literal word/phrase matching across stored parts; stale queries are cancelled so a completed older query never overwrites a newer one. Selecting a result or submitting Search dismisses the keyboard and sheet, lands at the match, and exposes a compact strip with Return to reading position. Offline across stored parts; inspection does not overwrite the original resume location, and no extra scroller wraps the article text. |
| End | Finish & archive · Back to Reader | Reaching the end does not choose either action automatically. |
| Finish feedback | Finished and archived · Undo | Article remains open; Undo restores prior list/completion and new credit, unless a later deliberate change supersedes it. |
| Highlight | Important · Copy · Share · Remove · Yellow · Green · Cyan · Purple | Compact sheet. The four stored colors are always presented with visible Y/G/C/P identifiers and their names; the selected one uses a black fill with a white identifier plus check/outline in monochrome. Single removal is immediate with Undo; multiple removals are confirmed. |
| Quote card | Source title · Open source · More · Important badge · Y/G/C/P · color name | Cards read source → full quote → compact actions. The source title and stored color identity sit above the complete quote; adaptive type is base +6sp up to 160 visible characters (grapheme clusters), base +3sp up to 450, otherwise base, never below the reader's chosen size. No six-line preview and no "Read full highlight". The 24dp Important star sits over the upper border in a reserved area (toggling it never moves the sentence) and announces "Important highlight". Every card shows its stored color as a visible identifier and name (e.g. Y · Yellow); monochrome uses distinct neutral fills with solid/double/dashed/dotted edge styles so identity survives gray compression. Open source (at least 48dp) and More (48dp) share one compact footer and do not trigger the card tap. Missing sources retain quote and attribution; attempting to open one uses the existing honest unavailable-source feedback. |
| Highlights | Newest · Important · Shuffle | Newest default; local quote/source-title search. Shuffle shows its own selected state, so it never reads as an unselected action. Changing order never advances Review, and feed filters do not redefine the persisted round. An empty result names the active constraint (query and/or Important) and offers Clear search plus Remove Important only when Important is actually selected. |
| Review from a quote | Revisit your saved passages · Continue · N left in this pass · Start another round | Tapping a highlight card presents that quote for Review without discarding an unfinished round: the round's cursor, queue, phase and Important-bonus history are preserved, the focused quote is reviewed once on Next, and leaving before Next keeps it for Continue. Entering Review records nothing, and a filtered result starts at that quote then continues the whole-highlights round. |
| Review entry | Review highlights · Start with your saved passages · Continue · N left in this pass · Revisit Important highlights · Start another round | A floating filled primary button above the bottom navigation (about 64dp, 16–20dp side gutters, review icon, full Role.Button semantics), not a top card. Monochrome uses black fill with white content; affordance never depends on shadow. Visible on arrival and at the top, hidden after ~16dp of deliberate downward scrolling and shown again on upward scrolling; hidden while the keyboard is visible, during selection, open sheets, confirmations and active Undo — the persistent header Review action always remains as fallback. Search text alone never hides it once the keyboard is dismissed. It is an overlay, so showing or hiding it never re-layouts the list, and the list reserves bottom room for the last footer. It reads persisted state only — it never starts, advances or repairs a cycle just to render. With no highlights the actionable empty state replaces it. |
| Review | Review · N left in this pass · Revisiting Important highlights · Source · Open source · Important · Share · Next | Compact Back + Review header; bottom navigation hidden. Source title, stored color identity and Open source stay in a fixed context row above the independently scrollable quote, so a long passage never hides its origin or source action. Comfortable reading measure on a neutral surface with the saved colour as a 3dp marker; the quote uses the shared adaptive type and reading font, and the Important star lives in a reserved top-trailing badge outside quote glyphs. The count is presentations left in the active pass including the current display: a focused queued quote counts once, an already-consumed focused quote counts its explicit extra presentation, and the bonus phase says so instead of folding into a base total. No fixed "X of Y" is invented while Important bonus items may follow. Exiting halfway resumes later. Deleted sources keep the quote and attribution and disable Open source honestly. |
| Review complete | Review complete · Back to highlights · Review again | Reaching the end of the round says Review complete with the primary Back to highlights and secondary Review again. No congratulatory or streak filler. |
| Search | All saved articles · Current list | Location separate from fields; all saved includes Archive. Shown as one compact context row, e.g. All saved articles · Title and text or Current list · Inbox · Title and text, plus Filter. |
| Search field | Search articles · Search highlights | One quiet 48dp surface shared by Reader and Highlights: 12dp corners, 20dp decorative icon, 16sp editable text, clear action (48dp) only when nonempty (Clear article search / Clear highlight search). Monochrome uses white fill with a 1dp dark boundary (2dp focused) instead of a heavy gray block. The field carries its own editable accessibility label. It focuses once per deliberate opening, so returning from an article does not reopen the keyboard. |
| Blank search | Use “quotes” for a phrase or # to choose a label. · Recent searches | Guidance and history show only for an unconstrained blank query. History rows are left-aligned with a history icon, the query and a separate restrained Remove target. |
| Search fields | Title and text · Titles only | Literal ordinary terms combine with AND; quoted phrases stay contiguous. Same local SQLite search on all devices; no FTS ranking or stemming claims. |
| Search feedback | Searching saved articles… · Check your search. | Distinguish pending, invalid, no matches and failed results. The active search does not depend on FTS indexing. |
| Filters | Sort · Filter · Clear filters | Visible removable constraints; labels combine with AND; Unlabeled excludes selected labels. |
| Labels | New label · Create label · Edit label · Save name · Merge labels? | Stable identities survive rename; collision merge explicit; unused labels retained. Deleting a label never deletes articles. |
| Settings | Reading appearance · Labels · Connected devices · Export · About Reader · Advanced | Technical diagnostics under Advanced; disconnect confirmed. |
| Export | Export articles & highlights | ZIP of articles/highlights; not a full backup of settings, keys or pairings. |
| Statistics | estimated reading minutes | Estimates from article length, not measured reading duration. |
